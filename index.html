عام اللعب الدردشة الغش الإدارة

قوانين عامة

  1. 1.1

    احترم جميع اللاعبين والإدارة. الإهانة والتحرش ممنوعان.

  2. 1.2

    جهل القانون لا يعفي من العقوبة. مسؤوليتك قراءة هذه الصفحة.

  3. 1.3

    ممنوع انتحال شخصية أي لاعب أو أحد أفراد الإدارة.

  4. 1.4

    ممنوع الإعلان عن سيرفرات أو مواقع أخرى داخل السيرفر.

قوانين اللعب

  1. 2.1

    ممنوع قتل اللاعبين بدون سبب (RDM) أو تعمّد إزعاجهم.

  2. 2.2

    ممنوع التخريب المتعمّد لمحاولات الآخرين أو لأهداف الجولة.

  3. 2.3

    ممنوع استغلال ثغرات الخريطة أو اللعبة (Bug abuse).

  4. 2.4

    ممنوع الانسحاب المتكرر أثناء الجولة أو ترك الفريق بدون عذر (AFK).

  5. 2.5

    العب ضمن فريقك ولا تساعد الفريق الآخر عن قصد (Teaming).

الدردشة والصوت

  1. 3.1

    ممنوع السب والشتم والعنصرية والتنمر بأي شكل.

  2. 3.2

    ممنوع التكرار والإغراق في الدردشة (Spam).

  3. 3.3

    ممنوع نشر معلومات شخصية لأي شخص بدون إذنه.

  4. 3.4

    ممنوع إزعاج الآخرين بالصوت (ميوزك، ضوضاء، صراخ).

الغش والبرامج

  1. 4.1

    ممنوع استخدام أي برنامج غش (Aimbot، Wallhack، Speedhack وما شابهها). حظر دائم

  2. 4.2

    ممنوع استخدام سكربتات أو ماكروهات تعطي أفضلية غير عادلة. حظر دائم

  3. 4.3

    ممنوع إنشاء حسابات متعددة للتهرب من الحظر أو العقوبة. حظر دائم

الإدارة والعقوبات

  1. 5.1

    قرار الإدارة نهائي داخل السيرفر. اعترض بأسلوب محترم وبدليل.

  2. 5.2

    العقوبات حسب المخالفة: تحذير، كتم، طرد، ثم حظر مؤقت أو دائم.

  3. 5.3

    للإبلاغ عن مخالف، افتح تذكرة في الديسكورد واذكر اسمه ووقت المخالفة مع تسجيل أو لقطة شاشة إن توفرت.

  4. 5.4

    تحتفظ الإدارة بحق تعديل القوانين في أي وقت.
